# TransLit
TransLit translates books into natural, culturally faithful editions — preserving the author's tone, idioms, and emotional essence.

## Project info

**URL**: https://maahir5858-translit-repo.netlify.app/


### Run this project loaclly

```sh
# Step 1: Clone the repository using the project's Git URL.
git clone https://github.com/maahir5858/TransLit_

# Step 2: Navigate to the project directory.
cd Translit_

# Step 3: Install the necessary dependencies.
npm install

# Step 4: Start the development server with auto-reloading and an instant preview.
npm run dev
```

### What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
